## Variant: Dense Utilitarian

### Design Stance
Tool-first, keyboard-centric, maximum information density — designed for power users who live in the calendar daily. Dark theme, monospace fonts, every pixel earns its keep.

### Key Choices
- **Layout**: Resizable three-pane (calendar | converter/events/festivals), collapsible splitter
- **Typography**: JetBrains Mono for data, Inter for UI; minimal labels, maximum signal
- **Color**: Dark slate-900 base, sky-400 primary, semantic amber/red/blue badges
- **Interaction**: Full keyboard control (arrows nav, T=Today, C=Compact, S=Swap), drag-resize panel, instant conversion

### Trade-offs
- **Strong at**: Speed, density, keyboard flow, always-visible context (converter + events + festivals), multi-timezone awareness
- **Weak at**: Visual breathing room, bilingual readability, casual discovery, accessibility for non-technical users

### Best For
Developers, researchers, power users, anyone who wants a terminal-like calendar they can drive without touching the mouse.
